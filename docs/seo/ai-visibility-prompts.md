# Prompts para monitorar a visibilidade em IA

Conjunto inicial (2026-10-16) para checagem manual e periódica (sugestão: mensal) em ChatGPT, Gemini, Claude, Perplexity e no Copilot do Bing.

## Como usar

- Rode cada prompt numa sessão nova, sem login quando possível, e anote: o MeetChat aparece? Em que posição? Com qual URL citada? A informação está correta (preço, grátis só no modo WhatsApp, lembrete por e-mail, sem integração com WhatsApp)?
- Registre numa planilha: data, ferramenta, prompt, menção (sim/não), URL citada, erro factual.
- Informação errada recorrente vira ajuste de conteúdo: a resposta direta no topo da página certa e o `llms.txt` (experimental).
- Não altere os prompts entre rodadas, para a comparação valer; acrescente novos no fim.
